# ShivaCalc — SkillCraft Technology Task 01

A modern responsive calculator for SkillCraft Technology Task 01.

## Features
- Addition, subtraction, multiplication and division
- Decimal numbers
- Percentage
- Positive/negative toggle
- Clear button
- Keyboard support
- Backspace
- Calculation history
- Dark/light theme
- Responsive mobile design
- No external libraries

## Run
Open `index.html` in any modern browser.

## GitHub Pages
1. Create a GitHub repository, e.g. `skill-calculator-task-01`.
2. Upload `index.html` and `README.md`.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/root`.
5. Save and wait for the Pages URL.
